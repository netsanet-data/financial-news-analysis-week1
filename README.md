# Financial News Sentiment Analysis - Week 1

## Project Overview

This project analyzes financial news headlines and explores the relationship between news sentiment and stock market price movement.

The project focuses on:

- Exploratory Data Analysis (EDA)
- Sentiment Analysis
- Financial News Processing
- Stock Market Analysis
- Technical Indicators
- Data Visualization

---

## Dataset

Dataset used:

- Financial news headlines
- Publisher information
- Publication dates
- Stock ticker symbols
- URLs

Total rows:
1,048,575

---

- Python
